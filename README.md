# Elha2: a food-saving app for Egypt

An Arabic-first mobile app and web portal that cuts food waste (Prevent · Sell · Donate). Built for the AUC Software Engineering course, Fall 2026.

| Path | What |
|---|---|
| `apps/mobile` | Flutter app (households and deal seekers) |
| `apps/portal` | React portal (businesses, NGOs, administrators) |
| `docs/specs` | SRS v1.0 and SDD v1.1 |
| `docs/sprints/sprint-1-demo.md` | How to run the Sprint 1 demo, with a click path per story |
| `docs/TODO-integrations.md` | What is needed to replace the demo's mocks with real services |

Project context for contributors and Claude Code: [`CLAUDE.md`](CLAUDE.md).
